# Changelog

## [0.1.0] - 2026-11-07
- Initial project release
- Added kernel initialization
- Added basic shell

## [0.2.0] - 2026-11-07
- Added command handler

Added commands:
- `help` - list of commands
- `poweroff` - powersoff MiniOS
- `reboot` - reboots MiniOS
- `echo` - echoes text
- `clear` - clears console
- `ver` - shows current version
- `wait` - waits n seconds
